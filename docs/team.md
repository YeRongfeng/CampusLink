## 协作约定

1. 接棒前按 README 启动，确认公共账号与上传可用；各模块只在自己的页面和后端目录内扩展。
2. 接口先确定请求字段、返回数据、登录要求和错误状态，再实现；沿用公共响应与用户身份。
3. 公共 User、认证、Layout、请求工具、全局路由及初始化 SQL 的修改先沟通，避免覆盖同学工作。
4. 每个模块完成后提供使用步骤和实际验证结果，通过 Git 提交供集成，不提交真实凭据与本地运行文件。
5. 集成时检查各模块入口、用户权限、数据库初始化与样式一致性，再更新全组文档。业务未实现的内容不能写成测试通过。

当前公共框架和相关文档已提供；三个业务模块、最终集成、部署目标及成员实名信息仍需后续补充。

## 文档共同责任

需求、数据库设计、程序设计、测试、部署维护和用户手册均由全组共同完成。公共框架负责人只承担结构搭建与公共部分，各模块负责人填写对应业务章节，集成负责人统一汇总；不将全套文档视为某一成员单独完成的成果。

成员姓名学号、具体任务完成情况及贡献说明在最终提交前据实填写；预留章节由相应负责人认领，不默认已完成。
