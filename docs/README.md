# 项目文档

本套文档是 CampusLink 全组项目的共同交付文档，覆盖公共基础、校园拼车、校园悬赏、二手书和系统集成。当前先填入公共框架已有内容，其余章节为各负责人预留，在同一套文档中逐步补齐。文档范围是整个系统，当前填写进度不代表整个系统已完成。

| 文档 | 内容 |
| --- | --- |
| [需求说明书](requirements.md) | 目标、用户、功能范围与验收要求 |
| [数据库设计说明书](database.md) | 全系统数据结构、公共用户表与三个模块的数据设计 |
| [程序设计说明书](program-design.md) | 总体架构、公共接口与三个模块的程序设计 |
| [测试报告](testing.md) | 公共功能、各业务模块及集成的测试结果 |
| [系统部署维护说明](deployment.md) | 全系统安装、配置、部署、维护和排障 |
| [用户手册](user-guide.md) | 用户操作及常见提示 |
| [工作分配安排](team.md) | 责任边界、交接与集成安排 |
| [公共框架设计与开发思路](framework.md) | 个人分工说明：框架负责人的设计思路及接入方法 |

快速运行见根目录 [README](../README.md)。

## 共同维护方式

- 六类文档及工作分配是全组材料；`framework.md` 单独说明公共框架负责人的工作。
- 模块负责人直接填写各文档中自己模块的预留章节，不另写互相脱节的整套文档。预留提示用于交接，不是已确定的业务设计。
- 已确认内容写明规则；未确定内容标注“待补充”；测试记录区分“未执行”和实际通过、失败结果。
- 集成负责人统一术语、接口、数据库关系和部署步骤，最终提交前补齐姓名学号并移除已完成章节的填写提示。
