# 测试报告

## 范围与依据

本报告面向 CampusLink 全系统，包含公共基础、三个业务模块及集成验证。当前仅公共框架部分已有实测记录；业务与集成部分在下方预留，尚未执行。已有公共测试环境为 Windows、本机 MySQL 8.4.11、FastAPI、Vue 开发服务器及浏览器。采用实际页面操作、少量接口请求及一次必要构建检查，不扩建测试体系。

以下汇总本次项目开发过程中已取得的结果，非本文撰写时重新执行全部测试。环境连通验证记录于 2026-09-17，公共功能与页面检查于 2026-09-18。

## 公共框架已验证结果

| 项目 | 操作与预期 | 实际结果 |
| --- | --- | --- |
| 环境连通 | 前后端启动，浏览器经代理请求健康检查 | 通过，数据库可用时返回 200 |
| 数据库不可用 | 停止本地 MySQL 后请求健康检查，再恢复数据库 | 历史验证通过，返回 503，恢复后重新返回 200 |
| 注册与登录 | 页面注册后预填用户名，使用新账号登录 | 通过，进入首页显示当前用户 |
| 资料修改 | 修改昵称，刷新后检查 | 通过，数据库和页面保留新昵称 |
| 头像保存 | 选择真实 PNG，上传并更新资料，刷新 | 通过，修正过头像插槽覆盖图片的问题，复查正常显示 |
| 模块入口 | 访问拼车、悬赏、二手书 | 通过，显示对应占位页面 |
| 登录保护 | 匿名请求当前用户接口；退出后访问 /ride/mine | 通过，接口返回 401，页面跳转登录 |
| 登录返回 | 从受保护入口重新登录 | 通过，返回 /ride/mine |
| 无效图片 | 登录后上传伪造图片 | 通过，接口返回 415 |
| 开发账号 | 执行账号初始化并使用 user01 登录 | 通过，三个开发账号创建，登录成功 |
| 页面适配 | 浏览器检查桌面、375px 手机首页和个人中心，展开手机导航 | 通过，已检查页面无明显挤压，菜单正常展开 |
| 构建 | npm run build（包含 vue-tsc） | 通过，类型检查及打包成功 |

## 当前验证限制

尚未形成可报告实测结论的项目包括：完整三模块业务、多人并发、性能与公网安全评估、新电脑从零安装、备份恢复演练。本报告不宣称这些项目通过。

本次最终效果记录未覆盖所有参数边界，例如每种图片格式、超限上传、全部 Token 边界和所有屏幕宽度；接口约束以实际代码和 API 文档为准。仓库保留的早期自动化测试不等同于本次已执行结果。

模块接棒后验证各自主要流程，集成时再走通“注册→登录→各业务主要操作→修改资料→退出”，将实际结果补充到本报告。运行测试脚本前确认使用独立测试库，禁止清理开发库。
