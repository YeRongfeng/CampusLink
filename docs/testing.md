拼车接口经 Vite 代理访问真实 MySQL 验证：匿名响应不包含联系方式；他人编辑与访客获取联系方式返回 403；发起人不能加入自己行程；超限人数、无效坐标、额外字段返回 422。两个账号同时争抢最后一个名额分别返回 200 和 409，重复报名不增加名额。退出释放名额并失去联系权限，可重新加入。有人报名后禁止编辑；取消后禁止报名及查看联系信息，历史仍保留。出发前不能完成，出发后不能报名，可完成且重复操作不重复改变状态。

浏览器已走通发布、编辑预填及保存、未登录报名跳转并返回详情、另一账号加入（剩余 3→2）、查看发起人联系信息、退出（剩余 2→3 且联系区消失）。缺少地图配置时出现手动输入提示，取消选点保留表单。前端类型检查与构建通过。详情重新加载失败时清除旧行程，避免残留旧数据。

本机保留少量明确标记的验证行程，用于查看已取消、已完成和可报名状态；未清理已有用户数据。

补充检查：375px 手机宽度下大厅筛选表单和行程卡片正常排列；迁移脚本重复执行成功；最终前端类型检查及生产构建通过。

用户配置真实凭据后，重启服务确认代理已启用。浏览器搜索“北京大学”显示 10 条建议，选择东门可显示地图标记；点击校园内地图位置可解析地址，确认后地点与坐标回填表单。修复高德 JSONP 被标为 application/json 导致 nosniff 阻止回调的问题：校验 callback 标识符及响应前缀后使用 JavaScript MIME，保留 nosniff。未调用用户当前位置定位，未发布测试表单。前后端 .env 均被 Git 忽略，凭据未写入报告。
