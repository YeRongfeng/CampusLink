# 需求说明书

## 目标与用户

CampusLink 面向校园学生，为校园拼车、校园悬赏、二手书提供统一入口。公共框架的目标是使三名模块开发者能够复用身份认证、资料、图片上传和页面布局，独立实现各自功能。

访客可浏览首页和模块入口；注册用户可维护自己的资料并访问“我的内容”。当前不设置管理员或其他角色。

## 功能范围

| 编号 | 需求 | 完成判定 |
| --- | --- | --- |
| F01 | 注册 | 用户名唯一；成功进入登录页并预填用户名，不自动登录 |
| F02 | 登录与退出 | 正确凭据可登录；退出清除本地状态；刷新能恢复有效身份 |
| F03 | 页面权限 | 首页与模块首页公开；个人中心及我的内容需登录，登录后返回原页面 |
| F04 | 用户资料 | 展示用户名、昵称、头像；可修改昵称和头像，不能修改用户名 |
| F05 | 图片上传 | 登录后上传 JPEG、PNG、WebP，最大 5 MiB，校验实际内容并返回 URL |
| F06 | 公共页面 | 首页、导航、登录注册、个人中心、404；手机可展开导航 |
| F07 | 模块开发空间 | Ride、Quest、Book 有独立目录、公开页、个人页和空 Router |
| F08 | 环境连通 | 健康检查真实访问数据库；可用返回 200，不可用返回 503 |

用户名限定 3–32 位英文字母、数字或下划线，存储前转小写；密码 8–128 字符；昵称去首尾空格后为 1–32 字符，注册未填写时默认用户名。表单错误应明确提示，提交期间避免重复提交。

## 公共约束

- 使用既定 Vue 3 / FastAPI / MySQL 技术栈，依赖版本固定；不使用 Docker。
- 所有业务接口沿用统一响应、身份依赖和数据库会话。业务数据不放入公共认证 Store。
- 密码只存 Argon2 哈希，JWT 密钥由环境配置；用户响应不含密码哈希。
- 页面统一绿色主题、公共容器和组件，适配桌面与手机。
- 数据库初始化不得删除已有数据，真实凭据和上传文件不提交仓库。

## 范围边界

目前三个业务模块仅显示“功能开发中”。其发布、浏览、参与和状态流转等具体需求由模块负责人定义后补充，不在公共框架中预设。当前不实现聊天、支付、积分、评价、后台管理、地图或第三方登录。

交付判定以实际走通“注册→登录→模块入口→修改资料与头像→刷新→退出→重新登录”为准，并执行前端类型及构建检查。公网部署、生产容量与性能指标不属于当前本地开发交付范围。
